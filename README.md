# The ARD Curriculum

> A personal, structured learning system for Web Development, UI/UX Design, Computer Science, and Software Engineering.

🌐 **Live Website:** https://ard-curriculum.vercel.app/

📦 **Repository:** https://github.com/A04runSP/ard-curriculum

---

## Overview

**The ARD Curriculum** is a personal learning roadmap designed to take me from foundational computer and programming knowledge to practical, professional-level software engineering ability.

The curriculum combines four major areas:

- 💻 Web Development
- 🎨 UI/UX Design
- 🧠 Computer Science
- ⚙️ Software Engineering

It is designed around a practical learning loop:

**Learn → Practice → Build → Review → Test → Ship → Reflect**

The goal is not to simply complete tutorials. The goal is to develop the ability to understand concepts, build real software, debug it, deploy it, and explain the decisions behind it.

---

## Learning Roadmap

The current curriculum is organized into progressive stages:

1. **Beginner** — computer and developer fundamentals
2. **Foundation** — programming mindset, command line, web and internet fundamentals
3. **Programming** — JavaScript fundamentals and problem solving
4. **Computer Science** — algorithms, data structures, complexity, systems and networking
5. **Web Development** — HTML, CSS, JavaScript, accessibility and APIs
6. **Frontend** — React, TypeScript, routing, state, forms, testing and performance
7. **UI/UX Design** — design fundamentals, UX, Figma, prototypes and design systems
8. **Backend** — Node.js, Express, APIs, authentication and PostgreSQL
9. **Databases** — SQL, data modeling, normalization, indexes and transactions
10. **Full Stack** — integrating frontend, backend, database, authentication and deployment
11. **Software Engineering** — Git, code quality, testing, architecture, refactoring and documentation
12. **DevOps** — Linux, Docker, CI/CD, environments, deployment and monitoring
13. **System Design** — scalability, caching, queues, load balancing and distributed-system concepts
14. **Advanced Engineering** — specialization, performance, observability, security and open source
15. **Professional** — capstone, portfolio, case studies and professional engineering practice

## Primary Technology Path

The curriculum intentionally avoids making a beginner learn dozens of technologies at once.

The main engineering path currently centers around:

```text
JavaScript
    ↓
HTML + CSS + Browser JavaScript
    ↓
React + TypeScript
    ↓
Node.js + Express
    ↓
PostgreSQL
    ↓
Full-Stack Applications
    ↓
Testing + Git + Software Engineering
    ↓
Docker + CI/CD + DevOps
    ↓
System Design
    ↓
Advanced Engineering
```

UI/UX Design is developed alongside the engineering path so that design and implementation can reinforce each other.

## Learning Philosophy

This curriculum is built around **ability rather than completion**.

A topic is not considered mastered simply because it has been read or watched.

The intended progression is:

| Level | Expected ability |
|---|---|
| Beginner | Explain the concept and follow examples |
| Intermediate | Build it independently |
| Advanced | Debug, optimize and adapt it |
| Professional | Design, maintain and explain it in a real system |

Projects and assessments are therefore part of the curriculum rather than optional decoration.

## Resource Philosophy

Resources are intended to support the curriculum rather than replace it.

Priority is given to:

- Official documentation
- University courses
- Open educational material
- High-quality technical books
- Reputable learning platforms
- Standards and specifications

Examples used throughout the curriculum include MDN, CS50, Full Stack Open, The Odin Project, official technology documentation, web.dev, W3C/WCAG material, Figma learning resources, and other reputable references.

Only legally accessible resources should be added to the project.
